Семинар 11
Требуемые условия завершения

Семинар: «Тестирование  деревьев: AVL, RB-Tree, Splay и BST»

Цель:  Выяснить  разницу в поведении структур данных на одних и тех же операциях, оценить асимптотику и аргументировать выбор структуры данных.

Формат: 4 команды (по типам деревьев) и 2 команды-аналитики. Все команды работают с одним и тем же набором входных данных.

 1. Задание  для команд 1-4

Выполнить реализацию дерева, поддерживающую:

1.       Операцию вставки: Node* insert(Node* root, int key)

2.       Операцию удаления: Node* remove(Node* root, int key)

3.       Операцию поиска: Node* find(Node* root, int key)

4.       Вывод глубины дерева и количества выполненных поворотов: void printStats() 

Базовая структура:

struct Node {

    int key;

    Node* left;

    Node* right;

Добавить в Node счетчик static long long rotations. В функциях поворотов (rotateLeft и т.д.) добавить  вызов rotations++. Для Splay — счетчик шагов splay.

 2. Задание для команд

Команда 1: AVL-дерево

Команда 2: RBT-дерево

Команда 3: Splay-дерево

Команда 4: BST

Команды 5 и 6 – аналитики:

1.           Реализовать  бенчмарк (tester.cpp):

-         генератор массивов: случайные числа, отсортированные числа, чередование min/max

-         таймер

-         measure(Node* (*insert_func)(Node*, int), const vector<int>& data).

Тест запускается  на трех наборах данных (каждый по 10 000 элементов):

-       Random: rand() % 100000.

-       Sorted: 1, 2, 3... 10000.

-       Hotspot (для Splay): 5000 раз число 42, затем 5000 случайных.
